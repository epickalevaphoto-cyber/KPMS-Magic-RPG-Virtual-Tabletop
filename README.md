# KPMS — Magic RPG Virtual Tabletop

Виртуальная платформа для проведения настольных ролевых игр по системе Harry Potter RPG.

## 🎯 Особенности

- Атмосферный минималистичный дизайн
- Экран игрока и мастера
- Интерактивная карта (в разработке)
- Система бросков кубиков (в разработке)
- Чат для общения (в разработке)

## 🚀 Запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build
